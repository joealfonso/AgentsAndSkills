# Prompt library

Each prompt lives in `prompts/<category>/<name>.md` next to this file. `prompts/about-me.md` holds Joseph's background and answer preferences.

## Running a prompt

1. **Pick it.** If Joseph names one, match loosely ("posting decoder" → `job-search/job-posting-decoder`). If he describes a task, pick the best fit from the index below and say which in one line. If two fit, name both and use the closer one.
2. **Load context.** Read `prompts/about-me.md` and apply it as background and answer rules.
3. **Fill the brackets.** Read the prompt file. Fill every `[BRACKET]` from what's already in the conversation. Ask once, in a single message, for anything essential that's missing. Optional brackets can be skipped.
4. **Run it.** Follow the prompt's instructions as if Joseph had pasted it, including its output format and its stop conditions.

If he asks for the prompt itself ("give me the prompt", "I want to paste it elsewhere"), return the filled-in prompt text in a code block instead of running it.

If no prompt fits, say so and do the task directly. Don't force a near miss.
