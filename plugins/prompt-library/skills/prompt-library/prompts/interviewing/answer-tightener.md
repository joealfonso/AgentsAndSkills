# Behavioral answer tightener

**Use when:** you've drafted or recorded an answer and it runs long or wanders

**You'll need:** the question, your answer (typed or transcribed)

## Prompt

```text
Tighten my interview answer.

Question: [QUESTION]
My answer: [PASTE]

1. Time it: estimate how long this runs spoken aloud.
2. Find where the point is. If it arrives after the first 20 seconds, flag it.
3. Mark what to cut: context the interviewer doesn't need, team process that hides my individual decision, repeated points.
4. Check it actually answers the question asked. If it answers a nearby question, say so.
5. Rewrite it to land under 2 minutes, keeping my wording wherever it's specific and only replacing what's generic.

If the answer is already tight and on target, say so and only suggest the one change that matters most.
```
