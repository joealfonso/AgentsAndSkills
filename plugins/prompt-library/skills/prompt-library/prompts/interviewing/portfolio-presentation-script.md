# Portfolio presentation script

**Use when:** you have a 45-60 minute portfolio review and need a structure and talk track

**You'll need:** the role, the 2-3 projects you'll show, time available

## Prompt

```text
Help me plan a portfolio presentation for [ROLE] at [COMPANY]. I have [MINUTES] minutes including questions.

Projects I'm considering:
[PROJECT: one-line summary, my role, outcome]

1. Pick the order (or recommend dropping one) based on what this role cares about. Explain in one line each.
2. Give a time budget per section, leaving at least 15 minutes for questions.
3. For each project, a talk track outline: the problem in one sentence, why it was hard, my key decisions (with what I rejected), the outcome, what I'd change. Mark the one moment per project that should get the most time.
4. Write the opening 60 seconds word for word: who I am and the through-line connecting these projects.
5. List the 5 hardest questions a skeptical panel would ask about these projects, and the one-sentence core of a good answer for each.

Favor fewer slides and more decisions. Flag anything that reads as process theater.
```
