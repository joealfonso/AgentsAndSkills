# AI pitch reality check

**Use when:** someone (or you) is proposing an AI feature and you want to test it before roadmap commitment

**You'll need:** the pitch or one-pager

## Prompt

```text
Reality-check this AI feature pitch.

[PASTE PITCH]

1. The user problem it claims to solve. Is there evidence that problem exists at this size? Quote the claim.
2. Would a non-AI solution (better defaults, search, a template, a rule) solve most of it cheaper? Be specific.
3. What accuracy the feature needs for users to rely on it, and whether that's plausible for the described approach.
4. The cost of being wrong, and who pays it.
5. Hidden work: data, evaluation, review staffing, monitoring, support.
6. Verdict: BUILD, BUILD SMALLER (describe the smaller version), or DON'T BUILD YET (name what evidence would change that).

If the pitch is sound, say so. Don't manufacture skepticism.
```
