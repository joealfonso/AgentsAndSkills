# Field notes template

**Use when:** before each research session, so every note-taker captures the same things, surprises included

**You'll need:** the research questions, the session type

## Prompt

```text
Make a one-page notes template for [SESSION TYPE, e.g. interview / usability test / site visit / support call review].

Research questions: [LIST]

The template should have:
- Header: participant ID, segment or attributes that matter for this study, date, session, note-taker.
- One section per research question, with space for observed behavior and direct quotes (kept separate from interpretation).
- A required "Didn't fit / surprised me" section, filled in after every session even if the answer is "nothing", for anything off-guide, contradictory, or odd. Quotes word for word.
- "Context that might explain this person" (setup, workarounds, history) so outliers can be interpreted later.
- A 3-line debrief to fill in within 15 minutes of the session: the most important thing we learned, the most surprising thing, and what to ask differently next time.

Format it so it can be pasted into a doc or spreadsheet with one row per session. Keep it to what a note-taker can realistically fill in live.
```
