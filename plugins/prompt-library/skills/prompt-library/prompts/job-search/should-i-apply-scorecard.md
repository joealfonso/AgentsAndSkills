# Should I apply? scorecard

**Use when:** you have several open roles and limited time, and need to decide where to spend it

**You'll need:** 2-5 postings, your priorities

## Prompt

```text
Help me decide which of these roles deserve my time.

My priorities, in order:
[e.g. 1. AI product work 2. Staff-level scope 3. Remote or Seattle 4. Comp at or above X 5. Healthy design culture]

Postings:
[PASTE EACH POSTING, separated by ---]

For each role, score 1-5 against each priority, citing the posting line behind each score. Where the posting doesn't say, score it "?" and name the question I'd need answered.

Then give a table: role, total, biggest unknown, and a recommendation (apply now / ask a contact first / skip).

Rank the roles. Don't reward a role for vague language; an unanswered priority is a "?", not a 3.
```
