# Following up on an application

**Use when:** it's been 1-2 weeks since you applied or interviewed with no word

**You'll need:** role, date applied or last contact, who you've talked to

## Prompt

```text
Write a follow-up for [ROLE] at [COMPANY].

Last contact: [DATE and WHO, e.g. "applied 10/3, no contact" / "final round with Dana on 10/10"]
Anything new worth mentioning (a relevant project shipped, an article, a competing timeline): [DETAIL or "nothing"]

Rules:
- Under 80 words. One purpose: get a status update or a timeline.
- If I have a competing offer or deadline, state it plainly and without pressure tactics.
- If there's nothing new, don't invent a reason to write. A clean "checking in on timing" is fine.
- No apologizing for following up.

Also tell me whether to send it now or wait, based on the timing above.
```
