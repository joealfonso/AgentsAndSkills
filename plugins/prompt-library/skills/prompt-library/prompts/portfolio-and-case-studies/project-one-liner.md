# Project one-liners

**Use when:** you need a crisp line for a portfolio grid, resume, intro or bio

**You'll need:** the project, the outcome

## Prompt

```text
Write one-liners for this project.

Project: [WHAT IT WAS]
Outcome: [WHAT CHANGED]
Where it'll appear: [portfolio card / resume / intro call / bio]

Give me 5 options, each under 15 words, each leading with the outcome or the hard problem, not the deliverable ("Redesigned the dashboard" is a deliverable). Vary the angle: scale, user change, business result, difficulty, the decision.

Then pick the strongest for the stated placement and say why in one line.
```
