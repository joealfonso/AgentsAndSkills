# daily-ops

Recurring personal routines, written to run as scheduled tasks.

**This is my setup, not a general tool.** The briefing is generic enough to work for anyone with Gmail and Google Calendar connected. The curator expects my own knowledge base MCP server (`kb_personal`), which isn't in this repo, so it won't run without a server that has the same tools.

| Skill | Runs | Needs |
|---|---|---|
| [morning-briefing](skills/morning-briefing/SKILL.md) | Daily, 7am | Google Calendar, Gmail |
| [kb-curator](skills/kb-curator/SKILL.md) | Weekly | The personal knowledge base MCP |

Both are short and conservative: the briefing flags only email that needs attention, and the curator archives only clear duplicates (it never deletes) and flags everything else for review.
