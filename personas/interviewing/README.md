# Interviewing personas

Rehearsal partners for job search stages beyond the portfolio review: the phone screen, a competing candidate, and the compensation conversation.

Each file is one persona: paste its instruction block into any chat with your material, or ask Claude to "review this as ..." with the `review-as` skill. **Review** personas do one pass and return a verdict; **rehearsal** personas stay in character for a practice conversation.

| Persona | Mode | Use for |
|---|---|---|
| [Compensation Negotiator](compensation-negotiator.md) | rehearsal | offer conversations, practicing holding a number under pushback |
| [Competing Candidate](competing-candidate.md) | rehearsal | sharpening what's actually differentiated before a final round |
| [Skeptical Recruiter (Screen-stage)](skeptical-recruiter-screen-stage.md) | rehearsal | practicing the initial phone screen, "walk me through your background." |

*This file is generated by `scripts/build.py` from the personas' frontmatter.*
