# Stakeholder and leadership personas

Practice and review for upward and cross-functional communication: execs, engineering leads, finance, skip-levels, a new manager you're coaching, and a board-level narrative editor.

Each file is one persona: paste its instruction block into any chat with your material, or ask Claude to "review this as ..." with the `review-as` skill. **Review** personas do one pass and return a verdict; **rehearsal** personas stay in character for a practice conversation.

| Persona | Mode | Use for |
|---|---|---|
| [Board-Level Narrative Partner](board-level-narrative-partner.md) | review | compressing a quarter of work into a short, decision-relevant story |
| [Cross-functional Eng Lead](cross-functional-eng-lead.md) | review | pressure-testing a spec before it goes to engineering |
| [Finance / Ops Stakeholder](finance-ops-stakeholder.md) | review | framing design work in terms leadership tracks at scale |
| [Skeptical VP / Exec Sponsor](skeptical-vp-exec-sponsor.md) | rehearsal | roadmap defense, exec-facing decks, anything that needs to land in one breath |
| [Skip-Level Manager](skip-level-manager.md) | rehearsal | practicing upward communication above your direct manager |
| [The New Manager You're Coaching](the-new-manager-youre-coaching.md) | rehearsal | practicing coaching rather than solving, fits an educator-for-junior-staff role |

*This file is generated by `scripts/build.py` from the personas' frontmatter.*
