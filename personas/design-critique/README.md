# Design critique personas

Reviewers for design and portfolio work: the senior designer, hiring manager, junior mentee, business stakeholder, research partner and AI specialist who find gaps before someone else does.

Each file is one persona: paste its instruction block into any chat with your material, or ask Claude to "review this as ..." with the `review-as` skill. **Review** personas do one pass and return a verdict; **rehearsal** personas stay in character for a practice conversation.

| Persona | Mode | Use for |
|---|---|---|
| [AI/ML Product Specialist](ai-ml-product-specialist.md) | review | pressure-testing AI feature design beyond the happy path |
| [Enterprise Stakeholder (Non-Design)](enterprise-stakeholder-non-design.md) | review | translating design decisions into business language before an exec review |
| [Junior Designer You're Mentoring](junior-designer-youre-mentoring.md) | rehearsal | stress-testing whether you can actually teach a concept, not just do it |
| [Research-First Partner](research-first-partner.md) | rehearsal | early-stage problem framing, before any UI gets discussed |
| [Skeptical Hiring Manager](skeptical-hiring-manager.md) | review | resume review, portfolio walkthroughs, interview answer prep |
| [Strict Senior Product Designer](strict-senior-product-designer.md) | review | case studies, portfolio decks, design rationale, anything going external |

*This file is generated by `scripts/build.py` from the personas' frontmatter.*
