# Prompt library

Paste-ready prompts for the things I do over and over in my career: job searching, interviewing, negotiating, portfolio work, user research, design work, AI product design, working with stakeholders, mentoring, writing, career growth, and building with AI.

**How to use one:** open it, fill in the `[BRACKETS]`, and paste it into any assistant. For better results, paste [about-me.md](about-me.md) above it first. In Claude, the `prompt-library` skill does both for you: say "use the job posting decoder on this" or "which prompt fits this?".

**How they're built:** every prompt asks for specific inputs, says exactly what to return, forbids invented facts, and tells the assistant to say so when the work is already good. That last part matters: it stops the model from manufacturing problems.

## Adding a prompt

Create `prompts/<category>/<name>.md` with `title`, `category`, `use_when` and `inputs` frontmatter, a `## Prompt` section with the prompt in a `text` code block, and `[BRACKETS]` for anything to fill in. Then run `python3 scripts/build.py` to update this index and the skill's. The `prompt-library` skill reads this folder through a symlink, so there's no copy to update. Use square brackets, not double curly braces: the site is built with Jekyll, which treats those as template code.
