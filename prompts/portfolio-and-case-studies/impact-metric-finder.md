# Finding the impact metrics

**Use when:** you know a project mattered but don't have the numbers ready

**You'll need:** what the project changed, what data might exist

## Prompt

```text
I need to show the impact of [PROJECT] and don't have clean metrics.

What changed for users or the business: [DESCRIBE]
Data that might exist: [analytics, support tickets, time studies, surveys, sales calls, adoption dashboards, anything]

1. List the metrics that would best prove the impact, from strongest to weakest, and where each one probably lives.
2. For each, the exact question I'd ask a PM, analyst or support lead to get it.
3. If no hard number exists, give honest qualitative evidence I could use instead (a quote, a decision that changed, a process that disappeared), and how to phrase it without overstating.
4. Flag any number I'm tempted to use that would not survive a skeptical follow-up question.
```
