# Portfolio site review

**Use when:** before sending your portfolio to anyone important

**You'll need:** your portfolio URL or page text, the roles you're targeting

## Prompt

```text
Review my portfolio as a busy hiring manager for [TARGET ROLE] who gives it 90 seconds.

[URL or PASTE TEXT]

1. What do you learn about me in the first 10 seconds? Is that what I'd want?
2. Which project would you click first, and why? Which would you skip?
3. Does the work show staff/principal-level scope (ambiguity, influence, systems, outcomes), or does it read as execution?
4. Copy problems: generic phrasing, "we" where it should be "I", jargon, missing outcomes. Quote the line.
5. The three changes that would most improve my odds, ranked.

Max 3 changes. If the site already does its job, say so.
```
