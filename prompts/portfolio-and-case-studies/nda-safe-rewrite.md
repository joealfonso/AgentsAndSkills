# NDA-safe rewrite

**Use when:** you want to show work covered by confidentiality

**You'll need:** the case study or description, what's confidential

## Prompt

```text
Rewrite this so I can show it publicly without breaking confidentiality.

[PASTE]

What's confidential: [company name, client names, exact metrics, product names, screenshots, internal tools]

1. Replace identifying details with accurate generalizations ("a Fortune 100 HR platform", "a 30%+ reduction" only if the real number is above 30%).
2. Keep the problem, decisions and reasoning intact; that's what reviewers judge.
3. Suggest how to rebuild visuals: redrawn wireframes, blurred data, a recreated flow.
4. List anything that still seems identifiable when combined with my LinkedIn.

Never round a number in the flattering direction.
```
