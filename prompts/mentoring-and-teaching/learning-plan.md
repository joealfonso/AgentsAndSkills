# Learning plan for a new skill

**Use when:** you or a mentee need to get competent at something new, fast

**You'll need:** the skill, current level, time available, why it matters

## Prompt

```text
Build a learning plan for [SKILL].

Current level: [DESCRIBE]. Time available: [HOURS PER WEEK, for how many weeks].
Why it matters: [THE REAL GOAL, e.g. prototyping AI features without engineering help]

1. Define "competent enough" as something I could show, not a course completion.
2. A week-by-week plan built around one small project that grows, not a reading list.
3. Primary sources only: official docs, original papers, practitioners' own writing. Name them.
4. The 2-3 traps people hit learning this, and how to skip them.
5. A checkpoint each week to know if I'm on track.
```
