# Building with AI

Getting good work out of coding agents: specs, CLAUDE.md files, delegation briefs, bug reports and critiquing what they build.

Fill in the `[BRACKETS]` and paste a prompt into any assistant, with [about-me.md](../about-me.md) above it, or ask Claude to use it by name through the `prompt-library` skill.

| Prompt | Use when |
|---|---|
| [Bug report an agent can fix](bug-report-for-agent.md) | something is broken and you want an agent (or engineer) to fix it in one pass |
| [Draft a CLAUDE.md for a project](claude-md-draft.md) | a repo needs agent instructions, or the existing ones are bloated |
| [Project brief to SPEC.md](project-brief-to-spec.md) | starting a side project or prototype with a coding agent |
| [Critique an AI-built prototype](prototype-critique.md) | an agent built something and you need to judge it before iterating |
| [Subagent or delegation brief](subagent-brief.md) | handing a task to another agent or session that starts with no context |

*This file is generated by `scripts/build.py` from the prompts' frontmatter.*
