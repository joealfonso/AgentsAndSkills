# User interview guide

**Use when:** you're about to run user or stakeholder interviews

**You'll need:** research questions, participant type, session length

## Prompt

```text
Write an interview guide.

Research questions: [LIST]
Participants: [WHO]
Length: [MINUTES]

Include:
- A 30-second intro script that sets expectations and asks for consent to record.
- Warm-up questions about their role and day.
- Core questions that ask about specific past behavior ("Tell me about the last time you..."), never hypotheticals or "would you use".
- Follow-up probes for each core question.
- A time budget per section.
- A closing question that catches what I didn't think to ask.

Flag any of my research questions that can't be answered by interviews.
```
