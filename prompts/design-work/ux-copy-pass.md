# UX copy pass

**Use when:** screens are designed but the words are placeholder, internal or vague

**You'll need:** the UI text, context on users and the flow

## Prompt

```text
Do a copy pass on this UI.

Context: [who uses it, what they're trying to do, tone of the product]
Strings (label each with where it appears):
[PASTE]

For each string that needs work: the original, a rewrite, and the reason in a few words. Principles:
- Buttons say what will happen ("Send invoice", not "Submit").
- Errors say what went wrong and what to do next, without blame.
- Internal or system names become user words.
- Nothing promises more than the product does, especially AI features.
- Shortest version that's still clear.

Leave good strings alone and don't list them.
```
